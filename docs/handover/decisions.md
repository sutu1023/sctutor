# 交接决策与后续建议

## 已确认的取舍

- 新公开仓库来自干净快照，旧历史留本地，不移交私人密钥、课件或学习记录。
- 不绑定接手人员的开发Agent。产品仍用LangGraph固定教学流程，模型通过独立适配契约替换，不把“可替换模型”变成“模型决定流程”。
- Python3.12/uv、FastAPI、SQLite与原生前端保持；单worker，不做公网生产身份。
- Docker Compose为简单本机启动入口；原生uv为开发/本机模型/Office入口。
- 原页/视觉保留macOS PowerPoint可选能力，文本路径不依赖Office；不伪造Linux渲染成功。
- 简明README → docs/handover索引 → 专题细节。Comet可选，净化正式证据但不复制本机运行状态。
- 保留生成后独立检查、角色归属、测验封锁、教师策略及失败闭锁；历史数字不冒充本轮通过。

## 公开前必须完成

1. 负责人选定代码许可证，核对依赖再分发义务和所有素材权利。
2. 对公开快照人工审查，轮换任何曾泄露的密钥；秘密扫描不能代替授权检查。
3. 下一组用自己的服务和课程做真实语义验收，尤其JSON、图像能力、提示等级、批改/自动审核；这不是离线模拟能证明的。

## 后续开发优先级（未包含在本轮实现）

- P0 若要公网：真正身份认证、教师授权、TLS、访问控制/速率限制、审计/隐私删除机制与威胁模型；先设计，不直接把Compose端口放到公网。
- P1 供应商能力契约测试与更大课程评测，监测模型升级/向量漂移；成本预算和可观测性，不输出密钥或草稿。
- P1 数据迁移工具与演练，让更换嵌入时保留学习数据有正式设计和回滚；当前换新数据目录不会自动迁学习记录。
- P2 跨平台真实原页渲染（例如LibreOffice），必须验证字体/动画/排版及安全，不能假设与PowerPoint完全一致。
- P2 教学效果和泄题率真人评估，掌握趋势与图谱体验；当前概率不是教育诊断，不外推固定小集分数。
