# 接手指南

先跑起来，再做离线回归，最后接自己的模型和课件。不需要安装特定 AI Agent 或 Comet。

| 你要做什么 | 去哪里看 |
|---|---|
| 启动、停止、升级容器，挂载自己的课件 | [容器部署](containers.md) |
| 接自己的大模型/嵌入服务 | [模型与配置](models.md) |
| 确认项目究竟做了什么、怎样验收 | [功能清单与验证方法](features.md) |
| 跑测试、记录本次结果 | [验证指南](verification.md) |
| 看懂代码、接口和扩展位置 | [开发导航](development.md) |
| 备份数据库、更换嵌入、排查故障 | [数据维护](operations.md) |
| 生成不含私人资料的新仓库 | [公开发布清单](publication.md) |
| 使用 Comet 接着开发 | [Comet 续接](comet.md) |
| 看交接取舍和待办 | [决策与后续建议](decisions.md) |

[本轮验证记录](results.md)只记录实际执行结果；模拟测试不是模型效果证明。
当前正式产品规格见 [完整规格](../comet/specs/guided-tutoring/spec.md)。历史规格里的个人语料和旧验收条件不应成为新课程的门槛，以最新交接条款为准。
