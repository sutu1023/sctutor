# 公开仓库发布清单

## 不在原仓库删东西

本次采用**新快照新仓库**，原仓库和Git历史保留。不要把当前目录直接全选上传，不用git clean清理课件。已忽略不代表历史没有泄露；疑似泄露先轮换密钥，不只删除文件。

```bash
# 标准库即可运行，不读取本地.env，不触发模型
python3 scripts/export_handover.py --history
python3 scripts/export_handover.py --output handover-export/review-1
```

Windows可用 `py -3` 替代python3。输出必须是handover-export下新目录，不覆盖旧快照。脚本按白名单选择当前磁盘文件，**包括尚未提交的必要功能**，而不是只用git archive。只保留代码、规则、静态资源、离线测试、依赖、容器文件、交接文档、Comet配置/规格；排除.env、课程、运行库、缓存、旧评测和本机Agent资料。旧live测试依赖原课程，不随快照发；新课程按验证指南自备评测。

文档中的个人绝对路径净化，历史MVP专属验收段落不交接；当前完整Requirement保留。旧档案默认不复制，必要决策在本目录说明。本轮最终归档后，导出会加上净化后的正式brief/verification文档，不拷贝本机Runtime或伪造可恢复Run。**DELIVERY.md标记待接受时不能作为最终交付**；最终接受归档后重新导出新目录。

扫描报告只显示位置，不打印秘密值。启发式扫描不能证明没有一切敏感信息；必须人工通读快照，并另用可信secret scanner检查（不要把私人文件上传第三方扫描网站）。SNAPSHOT.json记录导出时文件哈希，不是签名或安全保证。

## 发布前逐项确认

- [ ] 你有权公开源码，选定许可证；当前未自动添加LICENSE，不应宣称可任意使用。
- [ ] 检查依赖许可证/再分发义务（尤其PyMuPDF），如需要由负责人做法律评估。
- [ ] 无API KEY、个人资料、课件正文/图像/说明、原课程题答案、学习记录、备份或旧.env。
- [ ] 检查历史扫描疑点，泄露过的密钥已轮换；新仓库不复制旧.git。
- [ ] 检查DELIVERY.md及正式验收状态；待完成不是通过。
- [ ] 在快照目录无.env/旧课程运行uv sync、pytest、Ruff、JS检查、docker compose构建启动；步骤见验证指南。
- [ ] README和交接索引链接有效，下一组知道课件/密钥自备，Office可选、只本机演示。
- [ ] 停止测试容器，不删除任何用户数据卷。

全部确认后，**由持有发布权限的人**在快照目录初始化新的Git仓库、创建GitHub公开仓库并推送。导出脚本不提交/配置远端/push/创建PR。本次开发授权不自动包含这些动作。
