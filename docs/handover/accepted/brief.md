# Outcome
将当前工作区的 SC-Tutor 整理为下一组可通过 GitHub 公开仓库快速接手的项目：不交接私人密钥、课程 PPT 或学习数据；可自主接入模型；简化启动；提供已实现功能与可复现验证指南，并补齐交接缺项。公开交接采用清理后的新仓库快照，不携带旧 .git；原仓库和历史保留不改写。

# Scope
基于当前全部已提交和未提交成果开展单个 change，涉及配置、适配、流水线、测试和交接文档的一致契约，避免拆分后重复修改这些共享区域。
- 提供开发 Agent 无关的开发入口；保留 LangGraph 辅导编排。生成与嵌入独立可配，内置 OpenAI 兼容协议并定义其他协议的扩展契约、示例和测试；允许显式配置本机 HTTP 无密钥服务，但远程服务保留 HTTPS 及安全配置校验。供应商特例与核心流程隔离，不默认绑定原开发者账号/服务。
- 采用相对课程路径与空白密钥模板；提供无云端调用的配置/依赖自检和简短启动流程。无课件/无密钥可启动空应用，明确提示功能前置条件，不伪造学习内容。文本学习主路径无需 Office；原页/视觉是显式可选能力，关闭时流水线仍可完成文本知识处理，跳过状态不能记为已完成增强；开启但失败保持原失败闭锁。提供 Dockerfile 和 Docker Compose 本机容器启动，保留 uv 原生开发路径，不做公网生产部署。
- 默认离线测试使用合成数据，不依赖旧236页课程；真实课程检查显式可选且可传入新课程/评测数据。浏览器可配置可执行文件路径；离线 CI 不使用私人密钥/课件。
- README.md 使用简明自然语言，仅保留项目用途、最短启动步骤、关键安全/能力限制和交接导航，不堆叠配置表、长功能说明或历轮验证记录。详细内容统一进入 docs/handover/，由 docs/handover/README.md 按接手顺序索引，并说明每份文档何时阅读。功能矩阵核对代码、接口、自动化测试与人工步骤，记录真实验证结果和未验证项；提供架构、API、数据备份/迁移/嵌入重建、费用与安全边界、故障定位、后续建议。
- 容器使用锁定依赖和非root运行用户，默认单进程单worker；仅容器内监听0.0.0.0，Compose发布端口绑定宿主127.0.0.1，保留Host/同源/CSP/角色策略校验。凭据仅运行时注入，不复制进构建上下文/镜像；课件由接手人员挂载或上传，课件和SQLite数据持久化在镜像外，明确目录权限和备份方式。容器默认关闭Office增强；包含健康检查、启动/停止/重建/日志指南，停止或重建保留数据，删除卷需显式操作并警告。容器中的localhost指向自身，文档明确模型服务寻址；本轮不新增任意私网明文连接豁免，宿主模型可用安全HTTPS端点，原生路径支持显式loopback HTTP。
- 提供显式白名单快照导出工具及检查：涵盖当前未提交功能，拒绝打包密钥、课件、派生课件内容、运行数据库/缓存、.git 和本机 Agent 状态。审查候选内容，告知扫描的局限。只导出到新的忽略目录，不初始化远端或自动上传；历史只作只读风险检查，发现疑似泄露仅报告位置和轮换建议，不泄露秘密值。
- 保留可选 Comet 交接：.comet/config.yaml、净化后的当前完整总规格、必要决策/验收说明和本轮完成后的正式归档；提供安装/初始化入口及新 checkout 恢复方式，说明不复制 ~/.comet、本机会话/锁/路径。旧档案默认不随快照分发，用交接索引保留必要决策和可追溯说明。不要求非 Comet 开发者安装 Comet；本轮最终未接受前的快照不能冒称正式已验收交付。

## 目录结构
### 修改
- README.md / .env.example / .gitignore — 精简易懂的快速开始与交接索引、中立配置、公开仓库排除规则。
- src/sctutor/config.py / models.py / cli.py — 可配置模型接口、可移植路径、启动自检。
- src/sctutor/processing.py / rendering.py / app.py / static/ — 可选增强配置、流水线状态和界面提示，保留原有安全边界。
- tests/ / pyproject.toml — 无私有语料默认测试、浏览器路径、模型契约及交接回归。
- AGENTS.md — Agent 无关开发说明，保留当前仓库受管理区块；导出副本消除本机约束。
- docs/comet/specs/guided-tutoring/spec.md — 由 Runtime 在归档时发布目标规格，导出时净化历史专属路径与语料条件。
### 新建
- src/sctutor/providers.py — 模型适配契约及工厂，与供应商选项隔离。
- docs/handover/README.md — 交接文档总索引，说明阅读顺序和每份文档用途。
- docs/handover/ — 功能验收矩阵、架构/API、模型接入、数据维护、容器部署、公开发布及 Comet 续接指南。
- Dockerfile / compose.yaml / .dockerignore — 锁定依赖的非root镜像、仅本机端口发布、运行时配置及数据卷、构建上下文排除。
- scripts/ — 快照导出与脱敏检查，白名单明确且可测试。
- .github/workflows/ — 无密钥和私人课件的离线 CI。
### 明确不建
- 课程课件及生产学习数据分发包 — 用户明确不交接课件，学习数据不公开。
- 跨平台原页渲染器及可替换 Agent 编排框架 — 用户选择保留 PowerPoint 可选能力和 LangGraph。

# Non-goals
不自动提交、push、创建公开仓库、重写 Git 历史、删除本地课件或密钥；不做生产认证、公网部署、镜像推送或所有供应商原生协议实现；不承诺任意模型质量一致，不运行未授权的收费调用。许可证与课件版权列为发布前人工确认项，不擅自赋予开源授权；不移交旧课件正文、图像说明、评测题答案或学习数据。现有策略、角色隔离、生成后检查、有限调用及失败闭锁不能因可配置化而放松。

# Acceptance examples
- A1：干净快照按 README 使用 Python3.12/uv 锁定依赖安装，在无 .env、课件、Office、Comet 时启动本地空应用与健康/演示登录；自检无云调用，给出缺项与下一步；不会自动扫描私人目录或自动收费。
- A2：生成与嵌入分别配置地址、模型、凭据和适配器；模拟两套不同配置验证请求契约，供应商特例隔离，本机 HTTP/无密钥须显式配置，远程不允许不安全地址；错误不泄露密钥/上游正文，生成检查及向量校验不变；提供第三方协议适配示例与测试。
- A3：无需 Office 的文本入库、知识处理与学习链路有模拟集成覆盖；显式关闭增强显示跳过而非通过，开启增强失败仍阻塞；PowerPoint 与视觉前提及平台限制清楚，缺图不伪造原页。
- A4：默认 pytest、Ruff、全部前端 JS 语法检查不依赖私人目录/课件/密钥；离线 CI 使用合成夹具；浏览器烟测路径可配置，真实课程/供应商检查单独说明输入、收费和结果，未运行不算通过。
- A5：功能矩阵覆盖角色/会话、答疑阶梯/恢复/检查、检索/课件、资料权限、知识与题目审核、四题型小测、BKT/复测、报告/CSV、教师策略/匿名概览、可选联网和视觉；每类有入口、前提、测试或人工验证步骤、预期结果与已知限制，核对代码而非只复制旧报告。
- A6：快照白名单包含当前未提交的必要源码/静态资源/规则/测试/锁文件/文档，排除 .git、课件及派生内容、.env、data、缓存和本机状态；自动测试覆盖诱饵密钥/敏感文件排除或拒绝，扫描脱敏且注明局限，验证导出副本的安装/离线测试；原仓库和数据不被改写或清理。
- A7：交接含架构与 API 导航、模型切换与向量重建、数据库备份恢复/迁移、费用/隐私边界、故障定位和按优先级后续建议；无密钥/课件人员能按指南区分程序回归与真实模型验证；许可证、版权和密钥轮换为发布前人工关卡。
- A8：交接提供可选 Comet 路径，保留净化的配置/当前完整规格/必要决策和正式验收信息，说明新环境初始化与状态边界；不复制本机 runtime、会话或旧历史资料，不要求其他 Agent 安装 Comet。导出前未完成的验收明确标待完成，最终交付须引用已接受的正式结果。

- A9：Docker Compose从干净快照构建并启动，无私人配置也能健康检查和演示登录；非root/单worker，端口仅发布宿主127.0.0.1，原有安全拒绝仍有效；构建上下文和镜像不含私人密钥/课件/数据库。运行时注入配置，使用隔离合成数据验证挂载/上传及重建后数据保留；默认不调用Office/云端，文档明确容器模型寻址、权限、日志和删除卷风险。
- A10：根 README 仅简短说明用途、容器及原生启动、必要限制和交接入口，不堆叠配置/功能/历史验收细节；docs/handover/README.md提供按任务阅读的索引，详情各归其位，链接和命令可核对，不因精简丢失必要安全提示。

# Decisions
- 用户选择当前目录 main 开展任务；保留既有改动，不自动提交或推送。
- Q1=A：开发 Agent 无关；模型适配层可扩展，保留 LangGraph。
- Q2=A：基础功能跨平台；原页/视觉为 macOS + PowerPoint 可选能力。
- Q3=B：从清理快照新建公开仓库，旧历史本地保留；此决定不授权发布或历史重写。
- 用户补充：下一组也可能使用 Comet，保留必要交接文档；提供可选工作流而非强制依赖。
- 用户新增要求：增加容器化部署；README简单易懂、说人话，繁琐内容移至专门交接文件夹并提供索引与说明。此次新增A9/A10，不改变A1–A8。
- 已核实本机Docker客户端/服务端及Compose可用，计划实际构建与启动验证，不只检查配置文本；如镜像拉取/构建受网络限制，真实记录阻塞。
- 调查依据：当前默认及测试含个人课程绝对路径；真实检查部分绑定236页/16说明；配置仅支持HTTPS且模型参数按名称硬编码；已有OpenAI兼容接口与models注入入口可复用；浏览器脚本固定macOS Chrome。当前跟踪文件未含.env/PPTX/PDF/data，但尚不能认定内容安全。

# Verification expectations
离线检查与隔离临时库为默认；不读取/打印私人 .env 值，不使用生产学习数据做变更验证，不触发收费服务。真实供应商/Windows/Linux/Office实际验证按可用环境记录 not-run/blocked，不能用模拟结果冒充实机结果。快照应在临时隔离环境测试，不修改用户旧数据库。最终验收仍等待用户接受，不将本次需求选择视为结果接受。
