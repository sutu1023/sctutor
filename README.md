# SC-Tutor

一个用自己准备的课程 PPTX 做引导答疑、复习和小测的本地教学原型。
学生可以逐步获得提示、练习并查看学习报告；教师可以管理课件、审核知识和题目、调整辅导策略。

## 先跑起来

安装 Docker Desktop（含 Compose），在项目目录运行：

```bash
docker compose up --build -d
```

打开 **http://127.0.0.1:8000**，选择教师或学生演示账号。
不填密钥也能打开页面，但要使用 AI 功能，需要先复制 `.env.example` 为 `.env`，填写自己的生成模型和嵌入模型配置，再运行上述命令。

**课件请自行准备**：登录教师账号后上传 PPTX，再显式同步或处理。模型调用可能收费，上传本身不调用模型。数据保存在 Docker 卷中，停止用 `docker compose down`，不要随手删除卷。

## 本地开发（不用容器）

安装 [uv](https://docs.astral.sh/uv/)，然后运行：

```bash
uv sync --python 3.12 --locked
uv run sctutor doctor
uv run sctutor serve
```

需要 AI 时再复制并填写 `.env`。生成和嵌入可以用不同服务，也支持扩展接口。

## 使用前知道这几件事

- 这是**本机演示原型**，不是公网教学平台；演示账号没有密码，不适合考试防作弊。
- 不交接原开发者的密钥、课件或学习数据。不要把自己的 `.env`、课件和数据库提交到 GitHub。
- AI 可能答错，自动审核不等于人工保证。程序先检查再展示回答，但不能保证绝不泄题。
- 原页预览和图片增强需要 **macOS + PowerPoint**，默认关闭；容器使用文本模式。
- 未选定开源许可证；公开前请确认代码、依赖及资料的授权，见交接发布清单。
